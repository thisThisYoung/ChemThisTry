【English en】

ChemThisTry v0.1.5 — What's New

The in-app Agent gains an "Include current page as context" toggle (off by default) that attaches a screenshot and data summary of the active document to every message. GraphViewer's toolbar adds Baseline / Difference / Magnifier / Tangent / Text tools, tilted axes, and single-row or single-column legends. Project Explorer supports marquee selection, drag-to-folder, cursor follow after create, and F2 rename; DataViewer adds formulas, find & replace, and vertical text centering. Moleculer icons are redesigned with persistent cell thickness; Canvas gains text alignment and more stable large-image export. A new ActionTracker plugin shows live mouse and key activity, and the current view inserts into an open PowerPoint in one click. UI and Help are updated in 7 languages. Download.

ChemThisTry v0.1.5 — Nyheder

Den indbyggede Agent får en "Medtag den aktuelle side som kontekst"-kontakt (fraværende som standard), der vedhæfter et skærmbillede og et dataresumé af det aktive dokument til hver besked. Et nyt ActionTracker-plugin viser mus og taster live, og det aktuelle view indsættes i et åbent PowerPoint med ét klik. UI og Hjælp opdateres på 7 sprog. Hent.
